# 異世界闇商人

迷宮都市で商店を経営するブラウザゲーム。オリジナル設定で、固有名詞や世界観を既存作品から借りていません。

> 世界が滅びない程度に戦争を支え、世界が救われない程度に供給を絞る。
> あなたは迷宮都市の商人であり、この均衡そのものを商材にしている。

迷宮に潜るのは冒険者で、彼らは自分で売り先を持たない。持ち帰った品を鑑定し、値をつけ、必要な場所に届ける者がいて初めて商品になる。それがプレイヤーです。
勝ち負けの線は二本あり、**前線が崩れて世界が滅んでも負け、魔王が討たれて需要が消えても負け**。つまりこのゲームの目的はクリアしないことです。

## 動かし方

`prototype/ledger.html` をブラウザで開くだけ。ビルドもサーバーも要りません。

## 第一章の試作 — 迷宮都市の帳場

企画が面白いかどうかを最初に確かめるための最小版です。均衡も魔王も許可制度も、まだ乗っていません。

- 1ターン = 1週。**12週のうちに 2,500 G** 積めば店は続く
- 冒険者が品を持ち込む。多くは**未鑑定**で、こちらにできるのは見立てることだけ
- 言い値で買うか、値切るか、断るか。買い叩けば機嫌を損ね、次から来なくなる
- 在庫は**鑑定**してから店頭に出す。市場は未鑑定でも引き取るが、危険の分だけ値を引く
- **呪われた品は商品にならない**。掴めば処分費がかかる
- 週末に決算。家賃と店番の賃金が引かれる
- **目利き**は品の正体が分かるたびに上がり、見立ての誤差が縮む。ただし伸びは対数で、段が一つ上がるたび次の段には約1.7倍の学びが要る

面白さの芯は、**言い値(あちらの見立て)とこちらの見立てが食い違うところに儲けがある**という一点です。
逆に言えば、ここが退屈なら設定をいくら足しても面白くなりません。
