## 経緯 — 企画がどう決まってきたか

オーナーが一つずつ設定を足していく形で固まりました。順番に意味があるので、そのまま残します。

1. **ブラウザゲームとして作る。** 最初の指示は「まずボルタック商店、WIZ1の世界観を調べて」で、調査から入った
2. **迷宮で冒険者が拾った品を買い取り、市場に出す。輸出は国の許可を得て行う** — 商売の骨格
3. **魔王が現れ、各国の武具・補給品の需要が上がる。その価格操作も行う。迷宮産は地上の生産品より高性能** — ここで「戦時経済」が入った
4. **世界が滅びないように、需要がなくならないように経営する** — 勝敗の芯
5. **迷宮はクリアできないように、魔王は討伐されないように** — 上の線が二本あることが確定。「クリアしないことが目的」はここで決まった
6. **魔王領にも流通の窓口が要る。ゲームが進んだときに発生する** — 中盤の解放要素
7. **オリジナルへの転換。** オーナーの一言「もうWIZ1の世界とかけ離れたからオリジナルで」。
   → **以降、固有名詞と世界観は既存作品から借りていません。** 調査資料は買取50%・有限在庫・未鑑定品・鑑定リスクといった**仕組みの参考としてのみ**残してあります
8. **ネームド悪魔はソロモンの72柱**(Ars Goetia)。ソロモン没落後に魔界へ戻ったものを召喚する、という形
9. **天使は人体の免疫系の構造**を、悪魔と対照的に配置したもの
10. **終盤、魔王級に世界を理解すると自分の完結世界を持てる**。物資の移動と経営ができる
11. **タイトルは「異世界闇商人」**
12. リポジトリを作成して登録、第一章の試作を載せた

## 決まったこと

- **勝利条件は「クリアしないこと」。** 前線が崩れて世界が滅んでも負け、魔王が討たれても迷宮が踏破されても負け
- **核心のジレンマ**: 前線を支える資源と、それを取ってくる手段が同じ一つの蛇口から出ている。一つのレバーが二方向に効き、どちらの端にも破滅がある
- **四つのゲージ**: 前線 / 踏破 / 資金 / 嫌疑。前線と踏破は上下どちらの端も敗北
- **価格そのものが均衡の調整弁**。数字をいじる行為がそのまま世界の運命をいじる行為になる
- **成長は対数曲線の階段**。段差は倍率ではなく**新しい動詞**(値付け → どこに流すか → 買い占め → 誰を呼ぶか → 誰に標識をつけるか → 為替)。章がそのまま段
- **概念は探索依頼でしか手に入らず、それが踏破ゲージを押し上げる。** 平らになるのを防ぐ手段が、そのままゲームを終わらせる手段になっている
- **天使に顔は作らない。** 意識がないので買収も脅迫も説得もできない。描きにくさそのものが正しい
- **迷宮産の品もデータ。** 具現化には「器」が要るという案を採る方向
- **迷宮は作らない。** 探索はプレイヤーの仕事ではなく、冒険者が持ち帰った結果だけが届く。UI はダッシュボードと表とテキストで足りる
