# 攻略度(迷宮の深さ)を入れた記録(2026-09-20)

`prototype/ledger.html` に「攻略度」を入れ、初期所持金と目標を動かした。
**本物のスクリプトを Node で動かして**(`tools/sim.js`・描画を潰しただけ)、各 4,000 回。

## きっかけ(オーナーが遊んでの所見)

- 初期所持金が少なすぎる。
- 超高額の品が最初から出てくる。目標が「超高額の品が売れること」を前提にしている。
- → 超高額の品は**推定の攻略度**と結びつけ、武器の流通(売れた累計)+**売るたびのダイス**で攻略度を進める。

## 数字の裏づけ(変更前のコードから)

- 深層の品は正価 3,400〜5,200 G で、**目標 2,500 G より1個のほうが高い**。
- 未鑑定の言い値は 126〜280 G(正価の 1/12〜1/40)。**市場へ流すだけで正価の4割**(1,360〜2,080 G)。
- 深層の品を持ってくるミラは毎週 18%・**最初の4週で 56%・12週で 91%** の確率で来る。
- → 「勝敗は最初の2個で決まる」の正体。元手 600 G は、高額品の鑑定料(正価の15%=510 G)でも尽きる。

## 入れたもの

- **攻略度=階(整数・最深6)**。武器(短剣・長剣・斧槌・杖)が**店頭で売れる/市場へ流れるたび**、正価 ÷ 1,500 の確率(上限 0.6)で一階進む(**その後 ÷3,000 に変更**=下の追記)。防具・指輪・護符は数えない(オーナー裁定=最初は武器だけでバランスを見る)。
- **迷宮産の品の階 = その人が探索している階 + ずれ**。ずれは 0 が 90%・+1 が 9%・+2 が 1%(「地下1階で地下3階の宝」が稀に出る)。探索階は カイ=1 まで・ドゥナ/ヤン=2 まで・ミラ=攻略度そのもの。
- 品に階を付け直し、武器を足した(浅 3・中 1・深 2 本)。呪物も階ごとに置く。
- 画面には**幅のある推定だけ**を出す(ヘッダ「迷宮 推定 2〜4 階」)。真の階は隠し、推定の中心は週の締めごとに ±1 で引き直す。
- 所持金 600→**1,000**・目標 2,500→**1,800**。攻略度を入れる前のセーブは、目標 2,500 のまま続く(黙って変えない)。
- 踏破(=負け)の線は、第一章では**入れていない**(表示だけ)。

## 結果(NORMAL・各 4,000 回)

| 方針 | 変更前 | いま |
|---|---|---|
| 見立てを見ずに買う | 41% | **56.7%** |
| 見立て>言い値だけ買う | 45% | **63.0%** |
| (D-BOY / HARD で同じ方針) | 53% / 43% | 69.5% / 60.7% |

- 勝つ週の中央値は 5 のまま(10%点 3・90%点 9)。
- 12週の終わりの攻略度は平均 2.7 階。**3階以上 49%・4階以上 23%**(=深層の品が出る局面が試合の中で来る)。
- **「稀な深層」は稀**: 探索階より2階以上深い品を買ったのは 7% の試合。その試合の勝率は 86%(全体 57〜63%)。決めるほど多くはない。
- 攻略度を止めた対照(進まない)= 勝率 48.7% / 56.5% でタイムアウトが 11〜12%。**進むと +6 点**(深い品が出る帰還ループが効いている)。

### つまみの感度(NORMAL・見立て>言い値・攻略度の速さは 1,500)

| 動かしたもの | 勝率 |
|---|---|
| 初期所持金 800 / 1,000 / **1,200** | 48% / 62% / **75%** |
| 目標 1,500 / 1,800 / 2,200 | 65% / 62% / 60% |
| 攻略度の速さ(÷3,000 / ÷1,500 / ÷1,000) | 3階以上に届く率 23% / 50% / 57% |

- **初期所持金が最も効く**(±200 G で ±13 点)。目標は勝つ週を動かすだけで、勝率はほとんど動かない=勝敗が早く決まっている証拠。
- ÷3,000 では 12 週で 3 階に届く試合が 23% しかなく、攻略度が飾りになると見て ÷1,500 にしたが、オーナーが「進展は遅いほうがいい」と裁定し、÷3,000 に戻した(下の追記)。

## 追記(同日夕): 攻略度を遅く・D-BOY は呪物を必ず見抜く

オーナー裁定=「攻略到達度は進展が遅いほうがいいかも」「D-BOY は呪われたものを判別できるように」「D-BOY 自体が呪われているから分かる=**真の結末には届かない**」。

- 攻略度の速さを ÷1,500 → **÷3,000** に戻した(12週末に 3階以上へ届くのは 23%・4階以上 6%)。÷4,500 なら 13%・3%。進展が遅いぶん、深層の品は稀になり、勝率は約 2〜3 点下がる(NORMAL・見立て>言い値で 63%→60%)。進展の遅さを埋める役は「突発イベントで裏設定を進める」(未着手・下の提案)。
- D-BOY: 呪物は**必ず見抜ける**(`sight`)。持ち込み・在庫に「呪われている」と出て、目利き欄も「呪いは必ず見抜く」。勝つと「店は続く。ただし、呪われた者に真の結末は来ない。」(真の結末そのものは未実装=印だけ)。
- ★**呪物の見抜きが勝敗をほぼ決めている**(疑わしい品を避ける方針を足して回した・各 3,000 回・÷3,000):

| 難易度 | 見立て>言い値 | +「呪われている?」の印を避ける |
|---|---|---|
| D-BOY(必ず見抜く) | 67.4% | **100%**(破産 0%・勝つ週の中央値 4) |
| NORMAL(12%〜) | 60.2% | 75.2% |
| HARD | 57.2% | 73.1% |

  破産の原因はほぼ全部が呪物の掴まされ。見抜けるなら、序盤の外れは消える。**悪魔の使役(見抜き)を入れるなら、この強さを枠で絞る必要がある**(枠=目利き Lv・悪徳ごとに対応する悪魔=1体が見抜ける呪物は一部だけ)。

## まだ直っていないこと

- **「最初の3週で元手を割ったか」で勝ち負けが分かれる**: 3週目終わりで所持金 900 未満= 勝率 26〜36%(47%の試合)/ 以上= 83〜88%。変更前は 15〜18% 対 87% だったので**少し弱まっただけ**。
  原因は攻略度でなく、序盤の外れ(呪物 1/4〜1/3 で気づく率 12%・鑑定料)。**次に動かすなら呪物の率か序盤の仕入れの安全さ**。
- 難易度のつまみが勝率に効く幅は D-BOY 69.5%〜HARD 60.7%(9点)で、変更前(10点)と同じ。
- 数字は「操作役の方針」での値で、人が遊んだ感触とは別。**次は手で遊んでの確認**。
