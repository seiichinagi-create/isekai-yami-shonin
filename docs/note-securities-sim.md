# デザイナーズノート: 証券・FXシミュ(闇商人スピンオフ案)

「異世界闇商人」の均衡経営思想(世界を滅ぼさない程度に支え、世界を救わない程度に絞る)を、
現実の証券・FX業界(顧客を破産させず長く資金を注ぎ込ませる構造)に転用したスピンオフ案。
2026-09-22の雑談から出た着想メモ。まだ企画段階・未着手。

## コアコンセプト

カジノと証券・FX業界は「顧客資金をどれだけ長く・多く場に置かせるか」を最適化する構造が同型。
- ハウスエッジ = スプレッド/手数料
- ロスカット・追証 = "再起可能な負け方"の制度化(コンプに相当)
- 間欠強化(たまに勝てる)による依存形成

プレイヤーは運営側として「客を退場させない絶妙なライン」を調整するバランスゲームを行う。
勝たせすぎれば運営が損、負けさせすぎれば客が離脱する。

## 規制・危機シミュレーション層

ミクロ(個別顧客のリテンション)とマクロ(市場全体の崩壊回避)を両方絡めた二層構造。
プレイヤーは業者側と規制当局側を切り替えて遊べる。

- **レバレッジ規制と証拠金率急変は数学的に同値**(レバレッジ引き下げ=必要証拠金の引き上げ)。
  経済変調で資金余地が少ない局面でこれが発動すると、強制決済(投げ売り)という同じ出口に収束し、
  プロシクリカリティ(景気循環増幅)による連鎖崩壊を招く。1998年LTCM、2008年リーマン後の
  デレバレッジ連鎖、Basel規制批判などが参考事例。
- この構造は歴史上の「銀行の融資引き締めによる資産の安値収奪」(大恐慌期の農地差し押さえ、
  昭和恐慌期の地主制再編、アジア通貨危機時のIMF処方箋批判)とも相似形。
  「規制はルールの執行」という建前と「資産の強制的な安値収奪」が、発動タイミングと相手の
  資金繰り次第で同じ効果を生む。
- ゲーム上は、規制当局プレイヤーに「発動タイミングを恣意的にずらせる」裏メニューを持たせると、
  合法を装った収奪を実行できるダークな権力者プレイに発展させられる。

## 「耳寄り情報」システム

証券会社員からの投資情報は、フロントランニング・提灯(仕手戦)・タコ部屋営業など現実の
金融犯罪類型を下敷きにする。

- 表向き「あなたのために」と持ちかけられる情報ほど、実は出口流動性にされてるリスクが高い
- **本物の情報のときは、情報をくれた社員が行方不明になり、上司が専属担当になる**
  — 事後的な真正性の証明であり、同時にプレイヤーの「格上げ」(=会社にとって無視できない
  存在になった)を意味する。上司ルートでは離脱不可能性が強まり、半ば人質的な関係に変わる

## 消えた社員 救出サブクエスト(ドラクエ3・オルテガ型)

本筋に一切影響しない、得より寄り道コストの方が大きい任意クエスト。

- 救っても大した報酬はなく、救出後の姿も晴れやかではない(左遷先で腑抜けている、
  業界に絶望して足を洗っている等)
- それでも「見捨てなかった」という一点だけがプレイヤーに残る
- **さらに、救出したことで社員本人から逆恨みされる可能性もある**
  (惨めな姿を見られた屈辱、無関係な部外者に勝手に「救ってやった」立場を取られる反発)
- 見捨てれば良心が痛むだけで済むが、救えば恨まれるという新しい代償を背負う可能性がある
  — どちらを選んでも「無傷の勝利」は存在しない設計

## テーマ的な位置づけ

「決着をつける」ことは「その後の世界に責任を持つ」ことと同義。プレイヤーがずっと中途半端な
位置に留まり続けるのは、実は結末を引き受けないことで責任からも降りる狡猾な自己保身でもある。
`isekai-yami-shonin` 本体の「魔王を討てば需要が消えて商売が破綻し、前線を放棄すれば世界が
滅ぶ」という均衡思想と同じ構造を、証券業という別業態・別スケール(個人客ではなく市場全体)で
繰り返す形になる。

## ゲームオーバー画面の演出案

娯楽産業の「悪質客に散々サービスを提供した後で説教する」豹変行動のオマージュ。
本編中は景気の良い煽り文句で煽っておき、破産した瞬間に地味な色調・投資格言に切り替える。
格言は直前までゲーム自身が煽っていた行動と矛盾させると皮肉が倍増する
(例: 「レバレッジ上げましょう!」→ 破産後「過度なレバレッジは危険です」)。
破産の原因(過剰レバレッジ、狼狽売り、ナンピン地獄等)ごとに格言を出し分ける案もあり。
「搾り取られた上に説教される」という二重の理不尽さが、リベンジ動機(再挑戦)を煽る
リテンション装置として機能する。
