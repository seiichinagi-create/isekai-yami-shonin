# 第一章の試作を機械で回した記録(2026-09-19)

`prototype/ledger.html` の**本物のスクリプトをページ内で読み込み直し**(描画と保存だけ潰す)、方針を固定して 3,000〜6,000 回ずつ回した。移植ではないので、数字は試作そのものの性質。
数値はまだ直していない(企画書第10節=遊んだ感触が出るまで動かさない)。ここは「どこを見て遊ぶか」の材料。

## 結果

| 方針 | 勝ち | 破産 | 期日切れ |
|---|---|---|---|
| 全部言い値で買う・全部鑑定・正価で棚 | 2% | 98% | — |
| 未鑑定を9割で買う・鑑定できなければ市場・棚は正価の0.8・家賃が無ければ投げ売り | 43% | 55% | 2% |
| 同上+見立て>言い値のものだけ | 49% | 49% | 2% |
| 同上+カイの未鑑定を避ける(見立ては見ない) | 49% | 49% | 2% |
| 同上+鑑定料の表示から中身を読む | 52% | 46% | 2% |
| 値切りを8割に | 48% | 47% | |
| 値切りを7割に | 28% | 49% | |
| 鑑定済みの地上品だけ扱う | 0% | 92% | |

勝つときの週=中央値5(10%点は2週目)。破産の週=中央値4。

## 読み

1. **勝敗は二山で、決めているのは最初の2個**。
   最初に買えた2個がどちらも当たり=勝ち 83% / 1個が屑か呪物=42% / 2個とも=2%。
   「12週かけて積む」形になっておらず、**4〜5週目までに当たるか飛ぶか**。期日は 2% しか効いていない。
2. **方針の差が小さい**(まともな方針どうしで 43〜52%)。上手い下手が結果に出にくい。
   見立てを使う効果(+6点)は、**「カイの未鑑定を避ける」という固定の規則と同じ大きさ**=見立ての数字そのものはほぼ読まれていない。
3. **鑑定料の表示が正体を漏らしている**。鑑定料=正価の15% なので、ボタンの「鑑定に出す(225 G)」で 1,500 G の品と分かる(手で確認済み)。呪物も見かけ値から引くので、135 G 以外はほぼ一意に割れる。
4. **値切りは9割が常に得**(受諾 98%・機嫌を損ねない)。「言い値で買う」を押す理由が関係+1しかなく、関係の効きは言い値 −1.2%/点。
5. **地上品は飾り**。正価 5〜90 G に対して家賃+賃金が週 75 G。全部扱っても 0% 勝ち。
6. **呪物の率が高い**。迷宮産の抽選は清浄8:呪物4=1/3、Lv0 で気づく率 12%。元手 600 G は未鑑定2個+鑑定1回で尽きるので、外れ2回を吸収できない(1. の原因)。
7. 目利きは勝負がつく5週目までに Lv2〜3 止まり。成長の階段を感じる前に終わる。

## 遊ぶときの見どころ(人の手でしか分からないもの)

- 3週目あたりで「もう結果が見えた」と感じるか。
- 見立ての数字を実際に読んで判断しているか、それとも人(誰が持ってきたか)だけで決めているか。
- 値切りのスライダーを毎回 90 に合わせるのが作業になっていないか。

## 追記(2026-09-20): 難易度を入れた

オーナー指定= **D-BOY / EASY / NORMAL / HARD = 初期の鑑定成功率 100 / 50 / 33 / 10 %**。
試作の中でこれに当たる量は「目利き Lv0 のとき、未鑑定の品の見立てが**品そのものを見ている率**」(従来は 45% 固定=丸ごと読み違える率 55%)と読んで、そこに入れた。
段が上がるごとに +6 ポイントは従来どおり。誤差の幅(±45%)と呪いに気づく率(12%)は難易度で変えていない。
初回と「もう一度はじめる」で選ぶ。難易度を入れる前のセーブは 45% のまま続く(表示は「旧」)。

同じ方針を難易度ごとに 4,000 回ずつ回した勝率(試作の本物のスクリプトを Node で実行):

| 難易度 | 初期の率 | 見立てを見ずに買う | 見立て>言い値だけ買う | 見立て>言い値×2 だけ買う |
|---|---|---|---|---|
| D-BOY | 100% | 43.0% | 55.0% | 54.8% |
| EASY | 50% | 43.0% | 49.4% | 47.4% |
| NORMAL | 33% | 43.7% | 45.2% | 43.3% |
| HARD | 10% | 45.2% | 44.4% | 29.9% |

- 向きは意図どおり= **見立てを読む価値が D-BOY +12 点 → EASY +6 → NORMAL +1.5 → HARD −1**。HARD で見立てを信じて余白まで要求すると 30% まで落ちる(飾りの数字に従う罰)。
- ただし**幅が狭い**。上手に遊んでも D-BOY 55% と HARD 44% の差は 11 点しかない。見立てを見ない人の勝率は難易度によらず 43〜45% で動かない。
  = 上の「勝敗は最初の2個で決まる」がそのまま残っていて、**難易度のつまみが勝敗の主因に届いていない**。
  難易度を体感の差にするには、つまみを増やすより先に、元手600で外れ2回を吸えない構造(呪物 1/3・鑑定料が元手の 1/3)の側を動かす必要がある。
